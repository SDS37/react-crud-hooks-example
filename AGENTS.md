# AGENTS.md

An accepted spec in `specs/` is required before changing application code or dependencies. A chat message is not a spec. If the work is outside that spec, amend the spec and stop.

A change is done when every check in `docs/DoD.md` exits 0, and every extra check the accepted spec names. A written summary is not a check.

Branch off the default branch. Do not commit directly to it. Commit messages use Conventional Commits: `type(scope): reason`.

Do not initialize a code index. If the index is missing or names files that are not in the tree, ignore the index.
