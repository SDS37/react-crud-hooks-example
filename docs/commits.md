# Commits

Messages follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).

```
type(scope): reason
```

The reason is imperative, fits on one line, and says why. The scope is omitted when the change is the whole repository.

Types: feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert.

Commits land on a branch off the default branch. The default branch has no direct commits. Secrets and generated output stay uncommitted.
